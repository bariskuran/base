## Getting started

Dependencies are installed automatically when this project is created. Start the development server with:

```sh
yarn start
```

## Available scripts

| Command | Description |
| --- | --- |
| `yarn start` | Start with the published `@bariskuran/base` package. |
| `yarn start:local` | Start with a local Base source checkout. |
| `yarn build` | Build with the published `@bariskuran/base` package. |
| `yarn build:local` | Build with a local Base source checkout. |
| `yarn autoFill` | Generate route files from the project sitemap. |
| `yarn images:index` | Index image catalogs under `src/imageCatalog` and `public/imageCatalog`. |

## Project structure

- `public/imageCatalog` — public image catalog files.
- `src/assets` — project assets.
- `src/functions` — project functions.
- `src/hooks` — project hooks.
- `src/imageCatalog` — imported image catalog files.
- `src/views` — application pages.
